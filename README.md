# 1. Project Overview

This project implements a Federated Learning (FL) pipeline for skin lesion classification on the HAM10000 dataset. The goal is to train a global model collaboratively across 5 simulated clients (hospitals) without any client ever sharing the raw patient images

### What is Federated Learning?

In standard ML, all data is centralised on one server and a model is trained on it. In FL, data stays local. Each client trains on its own data and only shares model weights with a central server. The server aggregates these weights into a global model using `FedAvg` and sends it back. This protects patient privacy.  
### FedAvg - the aggregation algorithm


$w_{global} = \sum_{k}\frac{n_k}{n} * w_k$


Where:
- $w_k$ = weights returned by client k after local trainijg
- $n_k$ = number of training samples on client k
- n = total samples across al clients
- K = number of total clients (5 in this implementation)

Clients with more data have more influence on the global model - this is a weighted average, not a simple average.

### 6. Implementation Details 

### Non-IID Data Partitioning (`partition_data.py`)

**Dirichlet distribution** with $\alpha = 0.5$ creates Non-IID splits:
$p_k ~ Dir(\alpha)$ where $p_k = (p_0, p_1, p_2, p_3, p_4), \sum_{p_i} = 1$ 

For each class, a probability vector is sampled. Each entry tells what fraction of that class goes to each client. Lower $\alpha$ = more concentrated = more Non-IID.

**Client balancing:** After Dirichlet partitioning, all clients are downsampled to the size of the smallest client:

```python
min_size = min(len(cdf) for cdf in client_dfs)
client_dfs = [cdf.sample(n=min_size, random_state=seed) for cdf in client_dfs]
```

This ensures equal FedAvg weights (20% each), preventing any single client from dominating aggregation.

**Stratified train/test split:** 85% train, 15% test using sklearn's `train_test_split` with `stratify=df['dx']` to preserve class proportions in the test set.

### Model Architecture (`src/model.py`)
 
**MobileNetV2** — chosen for CPU efficiency.
 
Depthwise separable convolutions reduce computation by ~8-9x vs standard convolutions:

Standard conv: $C_{in} * C_{out} * K * K~ops/pixel$ 

Depthwise sep: $C_{in} * K * K + C_{in} * C_{out} ~ ops/pixel$

Example ($C_{in}$=32, $C_{out}$=64, K=3):

Standard:  18,432 operations

Depthwise:  2,336 operations  (~8x faster)

Final classification layer replaced for 7-class output:
```python
model.classifier[1] = nn.Linear(1280, 7)  # 1280 → 7 classes
```

Total trainable parameters: ~3.5 million
 
### Local Training (`src/client.py`)
 
**Weighted CrossEntropyLoss** for class imbalance:

$weight_c$ = $\frac{1}{count_c}$

$weight_{c_{normalized}}$ = $\frac{weight_c}{\sum weight_c}$

$Loss = -\frac{1}{N} \sum_i weight_{y_i} * log(softmax(outputs_i)_{y_i})$

Rare classes receive proportionally higher loss weights, forcing the model to learn them.
 
**SGD with momentum:**

$v_{t + 1} = \beta * v_t + \nabla L(w_t; batch)$ where $\beta = 0.9$

$w_{t+1} = w_t - \eta * v_{t + 1}$ where $\eta = current_{lr}$

**Weight decay (L2 regularisation):**

$w_{t + 1} = w_t(1 - \eta\lambda) - \eta * \nabla L$ where $\lambda = 0.0001$

**Fresh optimizer each round** — prevents stale momentum from previous rounds causing instability in Non-IID settings.

### FedAvg Aggregation (`src/server.py`)
 
```python
total_samples = sum(result["num_samples"] for result in client_results)
 
for result in client_results:
    weight = result["num_samples"] / total_samples
    for i, client_param in enumerate(client_params):
        aggregated[i] += weight * client_param
```

With equal client sizes (534 each), every client contributes exactly 20% to the global model.
 
### Decaying Learning Rate (`train_federated.py`)
 
Per Li et al. (2019), FedAvg with a fixed learning rate converges to a neighbourhood of the optimum, not the true optimum:

$||w^* - w_{fedavg}|| \ge \Omega (\eta)$

Decaying learning rate addresses this:
 
```python
current_lr = args.lr / (1 + 0.1 * round_num)
 
Round  1: lr = 0.009091
Round  5: lr = 0.006667
Round 10: lr = 0.005000
```

## 7. Design Decisions
 
| Decision | Choice | Reasoning |
|----------|--------|-----------|
| Architecture | MobileNetV2 | ~8x faster than ResNet on CPU |
| Optimizer | SGD + momentum | Adam's momentum state carries over rounds causing FL instability |
| Fresh optimizer | Yes, every round | Prevents stale momentum from previous round's gradient landscape |
| Local epochs | 2 | Balance between convergence speed and client drift |
| Batch size | 16 | Safe for 16GB RAM with 224×224 images |
| Alpha (Dirichlet) | 0.5 | Standard Non-IID setting in FL literature (Li et al., ICDE 2022) |
| Client balancing | Downsample to min | Prevents dominant client from controlling FedAvg (58.5% → 20%) |
| Loss function | Weighted CrossEntropy | Counteracts nv class domination (67% of dataset) |
| Learning rate decay | 1/(1+0.1×round) | Theoretically required for convergence on Non-IID data |
| Pretrained weights | False | Demonstrates FL from scratch; pretrained would improve results |

## 10. Known Limitations
 
### Class Imbalance
HAM10000 is severely imbalanced — nv (67%) dominates. Even with weighted CrossEntropyLoss, 10 rounds of CPU training was insufficient to fully overcome this. The model learned nv well (F1=0.81) but failed to learn most minority classes.
 
### Compute Constraints
Training on CPU with Intel Iris Xe (no CUDA):
- ~280 seconds per round with balanced clients
- 10 rounds = ~47 minutes total
- 10 rounds is insufficient for FL convergence on a 7-class imbalanced dataset
 
### Non-IID Client Drift
The oscillating test accuracy (between 11% and 67%) reflects the fundamental tension of Non-IID FL — clients train on different distributions and pull the global model in different directions. FedAvg averages these conflicting gradients, causing instability. FedProx would address this with a proximal regularisation term.
 
### No Pretrained Weights
MobileNetV2 was initialised randomly (`pretrained=False`). Pretrained ImageNet weights would provide a strong starting point, significantly accelerating convergence.

## 11. Proposed Improvements
 
### Immediate (code changes only)
 
**1. Pretrained MobileNetV2**
```python
# In src/model.py — change one line
model = build_model(num_classes=7, pretrained=True)
```
Loads ImageNet weights. The model already knows edges, textures, and visual patterns before FL training begins.
 
**2. More communication rounds**
```bash
python train_federated.py --num_rounds 50 --local_epochs 2
```
Standard FL papers use 50-100 rounds. 10 is not enough for a 7-class imbalanced dataset.
 
### Algorithmic improvements
 
**3. FedProx — reduce client drift**
 
Add a proximal term to each client's local loss:

$h_k(w;w^t) = F_k(w) + \frac{\mu}{2} * |w - w^t||^2$
This penalises clients for drifting too far from the global model — directly addressing the oscillation observed in results. Reduces client drift in Non-IID settings.
 
**4. FedNova — normalised aggregation**
 
Instead of weighting by sample count, FedNova normalises by local update counts — preventing clients with more local steps from dominating the global update.
 
**5. SCAFFOLD — variance reduction**
 
Introduces control variates to correct the gradient bias caused by Non-IID data distributions. Significantly improves convergence stability.
 
### Evaluation improvements
 
**6. Report macro F1, not accuracy**
 
For imbalanced datasets, accuracy is misleading. Macro F1 (equal weight to all classes) is the honest metric.
 
**7. Per-round per-class tracking**
 
Track F1 per class per round to observe which classes the model learns first and which remain difficult.
